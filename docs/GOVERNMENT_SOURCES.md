## US Government Sources

### US Treasury - OFAC (Office of Foreign Assets Control)

**Main Page**: https://ofac.treasury.gov/sanctions-programs-and-country-information/venezuela-related-sanctions  
**Recent Actions**: https://ofac.treasury.gov/recent-actions  
**Language**: English  
**Update Frequency**: As announced (often daily)

**Critical Data**:

#### Executive Orders
- **E.O. 14373** (Jan 9, 2026): Safeguarding Venezuelan Oil Revenue
  - Protects oil proceeds in US Treasury accounts from judicial attachment
  - Declares national emergency
  - URL: https://www.whitehouse.gov/presidential-actions/

- **E.O. 13884** (Aug 5, 2019): Blocking Property of Government of Venezuela
  - Froze all Venezuelan government assets
  - Prohibits US transactions with Maduro government

- **E.O. 13850** (Nov 1, 2018): Sectoral Sanctions
  - Targets oil, gold, financial, defense sectors
  - Authorizes designations of companies/individuals

#### General Licenses (Recent)

**GL 47** (Feb 13, 2026): Oil Majors Operations
- Authorizes Chevron, BP, Eni, Shell, Repsol to operate in Venezuela
- Requires payments through US-controlled Foreign Government Deposit Fund
- Does NOT allow transactions with China, Russia, Iran entities

**GL 46** (Jan 29, 2026): Venezuelan-Origin Oil Activities
- Authorizes US entities to handle Venezuelan oil
- Covers lifting, export, storage, marketing, refining
- Prohibition on gold/digital currency payments
- Reporting requirements: 10 days after first transaction, then every 90 days

**GL 5U** (Feb 2, 2026): PDVSA 2020 Bond
- Authorizes certain transactions related to PDVSA 2020 8.5% Bond
- Effective March 20, 2026

**GL 31B**: IV National Assembly Authorization
- Permits transactions with the 2015 opposition-led National Assembly
- Important for legal continuity claims

#### Specially Designated Nationals (SDN) List
- **Current**: 150+ designated individuals and entities
- **Recent Additions** (Dec 31, 2025): 
  - Aries Global Investment LTD
  - Vessels: DELLA, VALIANT, Nord Star, Lunar Tide, Rosalind
  - Shadow fleet operations

**How to Access**:
1. Visit https://ofac.treasury.gov/specially-designated-nationals-list-sdn-list
2. Search by name, vessel, or entity
3. Download full list (updated daily)
4. Check vessel IMO numbers against AIS data

## API Integration (Technical)

### OFAC SDN List API

```javascript
// Fetch SDN list
const response = await fetch('https://ofac.treasury.gov/specially-designated-nationals-list-sdn-list/download');
const sdnData = await response.text(); // CSV format

// Parse and filter for Venezuela-related entries
const venezuelaSDNs = sdnData
  .split('\n')
  .filter(line => line.includes('Venezuela') || line.includes('PDVSA'));
```

### OpenSanctions API

```javascript
// Query OpenSanctions for Venezuela
const response = await fetch('https://api.opensanctions.org/search/venezuela');
const sanctions = await response.json();

// Get National Assembly members
const assemblyResponse = await fetch('https://api.opensanctions.org/datasets/ve_asamblea_nacional');
const members = await assemblyResponse.json();
```

### US EIA API (Energy Statistics)

```javascript
// Requires API key from https://www.eia.gov/opendata/
const response = await fetch(
  'https://api.eia.gov/v2/international/data' +
  '?api_key=YOUR_KEY' +
  '&country=VEN' +
  '&product=CRUDE_OIL'
);
const productionData = await response.json();
```

## Critical Compliance Notes

### 🚨 Legal Warnings

1. **SDN List Compliance**: US persons CANNOT transact with anyone on SDN list without OFAC license
2. **50% Rule**: Entities 50%+ owned by SDNs are automatically blocked
3. **Secondary Sanctions**: Non-US persons risk US sanctions for dealing with Venezuelan oil sector
4. **General License Conditions**: Must comply with ALL terms (e.g., reporting requirements in GL 46)
5. **Legal Advice**: This monitor is informational only - not legal advice

### Who to Contact for Licenses

**OFAC Licensing**:
- Email: OFAC.Licensing@treasury.gov
- Phone: 202-622-2480
- Online: https://ofac.treasury.gov/ofac-license-application-page

**Average Processing Time**: 30-90 days (can be expedited for humanitarian cases)
